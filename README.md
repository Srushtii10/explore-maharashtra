# Explore Maharashtra – Discover the Land of Legends

Responsive tourism website (HTML, CSS, JavaScript). No build step, no backend.

## Files
- `index.html` – page structure
- `css/style.css` – styles and animations
- `js/app.js` – destination data, search/filters, planner, favourites, language toggle, forms
- `photos/` – your own destination photos

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Upload all files and folders, then Settings > Pages > Branch `main` / root.

## Notes
Contact and feedback forms are demo-only (stored in the browser). Verify timings, seasons and prices locally.
